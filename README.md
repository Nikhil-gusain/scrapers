# Web Scrapers

A collection of small Python automation tools for extracting structured data from websites and public web pages.

## Included tools

- Bus and transport data scrapers
- Reddit scraping experiments
- URL extraction utilities
- Web scraping experiments
- Response/data processing helpers

## Workflow

```
Target website
    ↓
HTTP request / page extraction
    ↓
Parse response
    ↓
Extract useful fields
    ↓
JSON / HTML output
```

## What this project demonstrates

- Python automation
- HTTP requests
- Web data extraction
- HTML parsing
- JSON processing
- Turning repetitive browser/web tasks into scripts

## Why I built it

Manual collection of repetitive web data is slow and difficult to reproduce. These scripts explore how common data-collection workflows can be automated and converted into reusable outputs.

## Status

A collection of learning and experimentation projects rather than one production scraper. Individual tools may require changes when the target website changes.
